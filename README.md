# 🚀 Python Selenium Autotest Course

Практический курс по UI-автотестированию на **Python + Selenium + Pytest**.

Вместе мы шаг за шагом напишем **полноценный проект автотестов с нуля**, который:
- можно использовать **как портфолио**
- легко адаптировать под **реальный рабочий проект**
- удобно **масштабировать и поддерживать**

---

## 🧩 Что будет в итоге

- Готовый UI-фреймворк на Python
- Понятная структура проекта
- Основа для масштабирования под реальные продукты
- Навыки, применимые в коммерческой разработке автотестов
